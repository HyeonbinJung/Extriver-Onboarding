# Extriver Partners — Influencer Email Outreach Playbook

> Version: 2026-10-17 · Internal operating guide · Owner: Extriver Partners
>
> 목적: 인플루언서 리드를 **발굴 → 검증 → 분류 → 맞춤 제안 → HTML 메일 발송 → 기록 → 후속 대응**까지 일관되게 처리한다. 그동안 요청한 한국/글로벌 파트너십 아웃리치 방식의 운영 원칙을 정리한 문서다.
>
> **중요:** 이 저장소의 시간별 리드 발굴 작업과 **실제 메일 발송 작업은 별개**다. 리드 수집/CSV 업데이트만 요청된 실행에서 Gmail 발송을 수행하지 않는다. 발송은 별도 명시적 캠페인 요청 및 발신 계정 권한을 기준으로 한다.

- 이전에 언급된 16~17개 파트너십, 특정 프로젝트·실적·예정 출시일은 **발송일 기준 사실 확인 후에만** 기재한다. 추정치나 예정치를 성과로 쓰지 않는다.

**우선 국가:** 한국, 영국, 미국, 홍콩, 인도, 캐나다, 싱가포르, 브라질, 호주. 사용자/캠페인이 지정한 국가를 우선하고, 확인된 리드가 부족하면 동일 분야의 인접 시장으로 범위를 넓힌다.

**플랫폼:** Instagram, YouTube, TikTok 우선. 업무 제휴 연락처 확인에는 공식 웹사이트·비즈니스 문의 페이지·LinkedIn 등도 활용할 수 있다.

**리드 발굴 방법**

1. 국가 × 주제 × 플랫폼으로 검색어를 구성한다. 예: “UK internship advice Instagram creator contact”, “Korean stock YouTube business email”, “Brazil finance TikTok collab”.
2. 활동성·콘텐츠 주제·타깃 독자·제품 적합성·청중 규모를 확인한다. 팔로워 수만 보고 고르지 않는다.
3. 공식 프로필의 bio, About, 사업 문의 버튼, 개인/브랜드 사이트 contact 페이지에서 **공개된 비즈니스 이메일**을 찾는다. 추측 생성, 패턴 추론, 비공개 연락처 수집 금지.
4. 이메일이 없으면 데이터베이스에 보존하되 **미확인/미발송**으로 두고 발송 대상에서 제외한다.
5. Instagram·YouTube·TikTok 핸들 및 URL과 플랫폼 **각각의** 팔로워/구독자 수를 기록한다. 검증되지 않은 수치는 공란으로 둔다.
6. 출처 URL, 지표 기준일, 확인 날짜를 기록한다. 다른 플랫폼 수치를 합산한 값은 단일 플랫폼 수치로 적지 않는다.

**리드 발굴 기본 배치:** 캐나다/싱가포르/브라질 같은 지정 국가에서 실행당 **금융·투자 10명 + 커리어·교육 10명** 조사. 매시간 반복 작업은 **리드 발견과 GitHub 데이터 업데이트만** 수행하며, 이메일 자동 발송을 뜻하지 않는다.

## 3. 저장소와 기존 데이터 구조

- Lead CSV: **data/extriver_influencer_leads.csv**
- Excel mirror: **data/extriver_influencer_leads.xlsx**
- 이 문서: **data/INFLUENCER_EMAIL_OUTREACH_GUIDE.md**
- 항상 **기존 행 보존 → 새 리드 검증 → 중복 제거 → 새로운 행만 누적 → CSV/Excel 동기화 → 커밋** 순서로 처리한다.
- CSV에 이미 존재하는 헤더를 유지한다: Country, Segment, Creator / Channel, Public business email, Email status, Instagram handle, Instagram URL, IG followers, YouTube handle / name, YouTube URL, YT subscribers, TikTok handle, TikTok URL, TikTok followers, LinkedIn URL, Source 1, Source 2, Metrics as of, Checked at, Outreach status, Verification notes.
- 중복 기준: 우선 **이메일 소문자·공백 제거**, 다음으로 정규화된 **플랫폼 프로필 URL/핸들**, 마지막으로 동일 창작자·브랜드의 다른 계정을 사람이 확인한다.
- 공개 저장소이므로 개인 이메일이 아닌 **창작자가 사업 문의용으로 직접 공개한 연락처**만 기록한다. 비공개 데이터, 내부 계약서, 발송 토큰/API 키, 사적인 메일 내용은 절대 커밋하지 않는다.
- 발송 시점 기록에는 CSV 상태값을 갱신하되 **발송 메시지 ID·시간·캠페인별 상세 로그는 접근 통제된 별도 CRM/로그**에 남긴다. 저장소의 공개 CSV를 내부 영업 활동 원장의 유일한 진실 공급원으로 간주하지 않는다.

## 4. 발송 전 체크리스트 (필수)

1. **실존 여부:** 타깃 채널과 공개 비즈니스 이메일의 연결이 실제 출처로 확인되는가?
2. **최근성:** 소셜 프로필 및 수신 연락처가 현재도 유효한가? 오래된 자료라면 재검증한다.
3. **이미 보냈는가?:** 리드 CSV/캠페인 로그와 **발신 Gmail의 Sent, 관련 스레드**까지 검색한다. 발신 계정이 여럿이면 모두 확인한다.
4. **제외 대상인가?:** 수신 거부(opt-out), 반송(bounce), 연락 금지, 이미 상담 중인 파트너, 명백히 부적합한 계정은 제외한다.
5. **누구에게 보내는가?:** 창작자 본인/매니저/운영팀에 맞춰 이름과 인사를 수정한다. 개인 이름을 모르면 “Hello [Channel] Team”과 같은 정확한 호칭을 쓴다.
6. **분야 적합한가?:** 금융 창작자에게 커리어 플랫폼을, 커리어 창작자에게 금융 터미널을 무작정 제안하지 않는다.
7. **팩트 체크:** 숫자·학교 이력·출시 일정·수수료율·IP 조건·실적·기술 라이선스의 사실 여부와 잠정 여부를 확인한다.
8. **준법·전달성:** 해당 국가 전자상거래/상업성 이메일·개인정보 규칙(예: 미국 CAN-SPAM, 영국 PECR/UK GDPR, 캐나다 CASL, 싱가포르 PDPA 등), 수신 거부 처리, 발신자 식별, 요구되는 주소/동의·예외를 확인한다. 국가별 적법성을 확인할 수 없는 수신자에게 자동 발송하지 않는다.
9. **미리보기:** 수신자, 제목, 링크, HTML·텍스트 대체 본문, 모바일 표시, 이미지 로딩을 확인한다.

**절대 금지:** 가짜 이메일 추정 후 발송, 이미 보낸 사람에게 반복 중복 발송, 근거 없는 “sent/delivered/read” 보고, 반송 주소 재발송, 미확정 조건을 확정된 계약처럼 말하기.

## 5. 제안서 작성 공식

**제목:** “[Creator/Channel] × Extriver Partners | [구체적 제품/가치]” 또는 한국어 “[(채널명)] 협업 제안 | [제품명]”.

**본문 구조 (약 150–260단어 영어 / 읽기 쉬운 한국어 4–6개 짧은 단락):**

1. **개인화된 인사:** 실제 영상·콘텐츠 주제/청중을 보고 1~2문장으로 왜 연락했는지 설명.
2. **팀 정체성:** Extriver Partners가 리서치·소프트웨어·제품 개발팀임을 짧게 설명. 학력은 확인된 사실로만 표현.
3. **청중의 문제:** 그 채널의 팬들이 겪는 구체적 문제를 정의.
4. **맞춤형 제품:** 2~3개의 핵심 기능과 왜 그 팔로워층에서 유효한지.
5. **제휴 모델:** 개발비 선납 없음, 개발/운영 역할, 창작자 IP 및 70/30 **협의안**. **Extriver Terminal 제휴 수수료 모델과 일반 공동 제품의 매출 분배는 별도 계약**이므로 혼용하지 말 것.
6. **명확한 CTA:** “15–20분 미팅 가능하신 시간 2~3개를 알려주실 수 있나요?” 또는 프로토타입/상세 제안서 전달 제안.
7. **서명:** Extriver Partners · 공식 웹사이트 · 확인된 LinkedIn · 수신 거부 안내.

**문체:** 과장 없는 전문적 톤, 자신감 있는 간결함, 대량 복붙 티가 나지 않는 문장, ‘상대에게 얻어갈 것’보다 ‘상대 청중이 얻을 것’ 우선.

## 6. 제품별 핵심 메시지 (작성 시 현황 재확인)

### A. 금융 — Extriver Terminal

- 문제: GS Quant, Fincept Terminal 등 강력한 금융·정량 분석 도구에 대한 관심은 있지만, 일반 이용자는 설치/배포, 영어 UI/설명, 금융 지식 장벽 때문에 실제 사용이 어렵다.
- 제안: **한국어 중심 웹/앱 인터페이스**, 리서치·시장 분석·초보자 친화적 설명 및 대시보드, 기존 분석 도구와의 **적법한 라이선스/연동 가능 범위** 검토.
- 대상 맞춤화: 미국주식 채널은 실적/밸류에이션, 거시경제는 금리·환율, 재테크는 기초 지표/예산, 부동산은 관련 시장 데이터 등으로 예시 조정.
- 가격 **초안:** Basic **월 ₩9,900**, Pro **월 ₩14,900**. 과거 모델링된 할인·추천 보상(예: 3개월 ₩5,000 체험 및 가정상 70% 추천 로열티) 역시 **검토 중인 예시일 뿐 확정 조건 아님**. 실제 적용 시 결제 수수료, 세금, 환불, 귀속 기준 명시.
- 필수 고지: “현재 세부 멤버십 플랜·가격·로열티는 모델링 중이며 확정된 사항이 아닙니다.” 제품이 사전 출시 단계라면 그렇게 명시.
- **주의:** GS Quant, Fincept, WorldQuant의 공식 파트너/기술 탑재가 **확정되지 않았다면** 그렇게 주장하지 않는다.

### B. 커리어·입시 — Freshman Internship Hub

- Stick Stories에 제안했던 방향을 기준으로 **영국/인도/홍콩/미국 등 지역별 학생·취준생에 특화**한다.
- 기능 예: 학년별 취업/인턴 로드맵, 채용 일정/지원 추적, 이력서·면접 자료, 실제 직무별 멘토링/커뮤니티, 알림·템플릿.
- 핵심 메시지: ‘짧은 영상의 정보’가 ‘학생이 반복 방문하는 실행형 플랫폼’으로 이어지게 한다.
- 창작자 팬층이 입시 중심이라면 진학 일정·서류 검토, 취업 중심이라면 인턴십·신입 채용으로 제안 방향을 바꾼다.
- 상대가 요구할 수 있는 항목: 포트폴리오/이전 프로젝트, 초기 프로토타입, 제품 일정, 개발·운영 역할, IP/수익 배분 설명.

### C. 한류·한국 문화 — Portal to Korea

- LoveSoo와 논의한 **Portal for Korean / Portal to Korea** 콘셉트.
- 한국 뷰티/식품/K-pop 굿즈/여행/체험 추천 및 커뮤니티·멤버십·리뷰·관심사 추천.
- 음식에는 알레르기·성분, 화장품에는 성분/피부 적합성 등을 제공하되 출처와 정확성 한계를 명시.
- Free/Plus/Premium, 위시리스트/가격 알림, 지역별 커뮤니티·리워드는 **아이디어**로 제시, 확정 기능처럼 약속하지 않는다.

## 10. 운영 순서 / 100명 발송 캠페인

**A. 발굴-only 작업**

Research → confirm public source → normalize/deduplicate → append existing CSV/XLSX → commit to GitHub → report **verified vs missing email**. **메일 발송하지 않는다.**

**B. 명시적으로 요청된 발송 캠페인**

1. 캠페인 목표를 기록한다. 예: “영국·홍콩·커리어 관련 국가의 **고유 수신자 100명**에게 제안 발송”.
2. 현재 Gmail Sent + 캠페인 로그 + CSV를 비교해 **이미 발송한 주소/옵트아웃/반송**을 걸러낸다.
3. 검증된 공개 비즈니스 이메일 중 적합한 수신자를 선정하고 국가/세그먼트를 나눈다.
4. 해당 분야 제안 → 개인화 → 현지어 HTML/텍스트 → 미리보기 및 준법 확인 → 실제 계정에서 발송한다.
5. 실제 메일 API의 **send 성공 결과**를 받은 건만 “sent”로 집계하고, 가능하면 메시지 ID/시각을 비공개 로그에 기록한다. **Sent ≠ delivered/read**.
6. 충분한 리드가 없으면 **재발굴 → 이메일 확인 → 중복 검사 → 발송**을 다시 수행한다. 타깃(예: 100 **고유** 수신자) 달성 여부를 누적으로 추적한다.
7. 속도 제한·계정 오류·적법성 불명확·확인 가능한 수신자 소진 등 장애가 발생하면 **발송을 멈추고 그 사유와 현재 성과를 정직하게 보고**한다. 가짜 주소 생성, 제한 회피, 무한 재시도로 채우지 않는다.
8. 캠페인별 결과는 전체 검토 수 / 공개 이메일 확인 수 / 신규 고유 발송 성공 수 / 중복 제외 / 반송 / 응답 / 수신 거부 / 잔여 목표로 보고한다.

**후속 연락:** 상대가 답변하지 않았다고 즉시 반복 메일을 보내지 않는다. 국가별 규칙과 상대의 의사를 존중하고, 제품에 관한 실질적 새 정보가 있을 때 제한적 follow-up만 진행한다. 거절/수신거부면 추가 연락하지 않는다.
